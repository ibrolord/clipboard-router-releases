# Clipboard Router

Clipboard Router is a native macOS clipboard workspace for capturing, finding,
saving, and organizing what you copy. It includes menu-bar access, notes,
folders, reviewed actions, Private Sessions, and an authentication-gated Vault.

## Requirements

- macOS 14 Sonoma or later
- Apple Silicon for the initial 0.1.0 release

## Install

The signed and Apple-notarized download will be attached to the `v0.1.0`
release in this repository.

Homebrew installation will be available from the companion tap:

```bash
brew install --cask ibrolord/tap/clipboard-router
```

Clipboard Router 0.1.0 is an initial free release. It does not require a
purchase or license key.

## Security

Download only from this repository or the `ibrolord/tap` Homebrew tap. Every
release includes a SHA-256 sidecar, is signed with the Clipboard Router
Developer ID certificate, notarized by Apple, and checked by macOS Gatekeeper.
